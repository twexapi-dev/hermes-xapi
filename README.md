# hermes-xapi
A Hermes Agent plugin that enables X (Twitter) automation through TwexAPI.

## Related Hermes X/Twitter Plugins

- [Hermes Tweet](https://github.com/Xquik-dev/hermes-tweet) - Native Hermes Agent plugin for X/Twitter search, profile/timeline reads, and optional posting/follow actions. Read tools require `XQUIK_API_KEY`; actions require explicit `HERMES_TWEET_ENABLE_ACTIONS=true`.
